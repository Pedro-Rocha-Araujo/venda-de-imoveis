# Venda de Imóveis 🏠

### 🧩 Características do Projeto:
* Arquitetura MVC no backend do projeto
* Autenticação de usuário com Json Web Token

### 🔧 Ferramentas Usadas
* ReactJS + (React-Toastify, React-Router-Dom)
* NodeJS | ExpressJS
* MongoDb | Mongoose

### ⚙️ Funcionalidades
* Cadastro e Login de Usuários
* Possibilidade de cadastrar Inóveis para venda
* Possibilidade de fazer propostas por imóveis
* Visualizar as propostas feitas na página de perfil
